🗄️ MinIO 文件存储服务

基于 MinIO 的高性能对象存储解决方案，支持文件上传、下载、删除等完整功能。适用于物联网设备数据、视频监控、工业日志等场景。

服务配置

应用端口 28080
MinIO 端点 http://localhost:9000
访问密钥 minioadmin
默认桶名 my-bucket

核心特性

  • 高性能文件上传（最大 100MB）
  • 预签名 URL 安全访问
  • 自动 UUID 文件名生成
  • 灵活的过期时间控制
  • 文件存在性检查
  • 一键删除管理

应用场景

  • 物联网设备数据存储
  • 视频监控录像管理
  • 工业传感器日志
  • 边缘计算数据湖
  • AI 训练数据管道
  • 车联网数据采集

📡 API 接口文档

POST /api/files/upload
功能说明：上传文件到 MinIO 存储，返回预签名访问 URL（默认 7 天有效期）
参数名 类型 必填 说明
file MultipartFile 是 要上传的文件对象
💻 cURL 示例
# 上传文件 curl -X POST \ -F "file=@test.png" \ http://localhost:28080/api/files/upload
✅ 响应示例
http://127.0.0.1:9000/my-bucket/a1b2c3d4-e5f6-test.png?X-Amz-Algorithm=AWS4-HMAC-SHA256&...
⚠️ 注意：上传文件大小限制为 100MB，超出将返回 413 错误。
GET /api/files/{objectName}
功能说明：生成文件的临时访问 URL，可自定义过期时间（推荐用于生产环境）
参数名 类型 位置 说明
objectName String 路径参数 对象名称（UUID-原始文件名）
💻 cURL 示例
# 获取 1 小时有效期的访问 URL curl http://localhost:28080/api/files/a1b2c3d4-e5f6-test.png
✅ 响应示例
http://127.0.0.1:9000/my-bucket/a1b2c3d4-e5f6-test.png?X-Amz-Algorithm=AWS4-HMAC-SHA256&...
⚠️ 建议：过期时间设置为 300-3600 秒（5分钟-1小时），确保安全性。
GET /api/files/check/{objectName}
功能说明：检查指定对象是否存在于 MinIO 存储中
参数名 类型 位置 说明
objectName String 路径参数 对象名称
💻 cURL 示例
# 检查文件是否存在 curl http://localhost:28080/api/files/check/a1b2c3d4-e5f6-test.png
✅ 响应示例
true // 或 false
DELETE /api/files/{objectName}
功能说明：从 MinIO 存储中永久删除指定对象
参数名 类型 位置 说明
objectName String 路径参数 要删除的对象名称
💻 cURL 示例
# 删除文件 curl -X DELETE http://localhost:28080/api/files/a1b2c3d4-e5f6-test.png
✅ 响应示例
文件删除成功
⚠️ 警告：删除操作不可恢复，请谨慎使用！

🚀 MinIO 部署指南

🐧 Linux 部署
docker run -d \ --name minio \ -p 9000:9000 \ -p 9001:9001 \ -v /data/minio/data:/data \ -e "MINIO_ROOT_USER=minioadmin" \ -e "MINIO_ROOT_PASSWORD=minioadmin" \ minio/minio:RELEASE.2025-04-22T22-12-26Z \ server /data --console-address ":9001"
🪟 Windows 部署
docker run -d --name minio -p 9000:9000 -p 9001:9001 ^ -v D:/minio/data:/data ^ -e "MINIO_ROOT_USER=minioadmin" ^ -e "MINIO_ROOT_PASSWORD=minioadmin" ^ minio/minio server /data --console-address ":9001"

端口 用途 说明
9000 API 服务 MinIO 对象存储 API 端点

🏗️ 技术架构

核心技术栈
  • Spring Boot 3.x - 现代 Java Web 框架
  • MinIO SDK - 官方 Java 客户端库
  • S3 兼容 API - 标准对象存储协议
  • 预签名 URL - AWS Signature V4 算法
  • UUID 命名 - 避免文件名冲突
  • 自动桶创建 - 智能初始化存储桶
数据流向
客户端 → Spring Boot API → MinIO Client → MinIO Server ↓ ↓ 预签名 URL ← ← ← ← ← ← ← ← ← ← 存储确认

❓ 常见问题

Q1: 为什么上传的文件名会变成 UUID 格式？

A: 为避免文件名冲突和保证唯一性，系统自动生成 UUID-原始文件名 格式。这样即使多个用户上传同名文件也不会覆盖。

Q2: 预签名 URL 过期后怎么办？

A: 调用 GET /api/files/{objectName} 接口重新生成新的临时访问链接。建议根据业务需求设置合理的过期时间。

Q3: 如何修改默认存储桶名称？

A: 编辑 application.yml 文件中的 minio.bucket-name 配置项，重启应用即可。

Q4: 支持哪些文件格式？

A: MinIO 支持所有文件格式（图片、视频、文档、二进制等），单个文件最大 100MB。如需更大文件，请调整配置文件中的 max-file-size。

Q5: 如何在生产环境确保安全？

A: 建议：① 修改默认 access-key/secret-key；② 使用 HTTPS；③ 设置较短的 URL 过期时间；④ 启用 MinIO 服务端加密；⑤ 配置访问控制策略。
