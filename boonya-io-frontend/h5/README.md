# Boonya IoT H5 移动端

基于 Vue 3 + TypeScript + Vant UI 开发的 IoT 设备监控 H5 应用。

## 🚀 技术栈

- **Vue 3** - 渐进式 JavaScript 框架
- **TypeScript** - 类型安全
- **Vite** - 快速构建工具
- **Vant UI** - 移动端组件库
- **Pinia** - 状态管理
- **Vue Router** - 路由管理
- **Axios** - HTTP 请求

## 📦 安装

```bash
npm install
```

## 🔧 开发

```bash
npm run dev
```

访问: http://localhost:3001

## 🏗️ 构建

```bash
npm run build
```

## ✨ 功能

- ✅ 用户登录
- ✅ 设备列表
- ✅ 设备详情
- ✅ 下拉刷新
- ✅ 上拉加载
- ✅ 响应式设计

## 📱 页面

- `/login` - 登录页
- `/devices` - 设备列表
- `/device/:id` - 设备详情
